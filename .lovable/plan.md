# خطة التعديلات

طلبك يحتوي على ١٥+ تعديل في أماكن مختلفة. سأنفذها على مراحل، وأبغى تأكيد قبل ما أبدأ.

## ١. لوحة الأدمن (مدير القسم)
- إخفاء قسم **To Do / Done** السفلي عند الأدمن — يكفي القسم العلوي (Department Inbox).
- باقي الأعضاء (Editor → سيتم تسميتهم **Employee**) يبقى عندهم نفس العرض.
- استبدال كلمات الصلاحيات: **Admin / Editor / Viewer** → **Admin / Employee** فقط (حذف Viewer).

## ٢. تفاصيل التاسك
- لمن يضغط الموظف على التاسك تظهر **كل التفاصيل** يلي كتبها المدير (وصف، ديدلاين، مرفقات، اسم مرسل التاسك، اسم مدير القسم).
- في الأسفل: زر **موافقة على المهمة** + زر **طلب تعديل** (يختار موظفين، يكتب وصل، يرفع ملفات).
- إصلاح **Upload failed: Bucket not found** بإنشاء bucket للملفات + سياسات RLS تسمح بالرفع والتحميل.

## ٣. صفحة المدير العام (ManagerTasks)
تقسيم التاسكات لثلاث أعمدة بدل اثنين:
1. **مرسلة — لم تُنفذ بعد**
2. **نُفذت — بانتظار المراجعة**
3. **نُفذت وتمت المراجعة**

إظهار: الديدلاين، وقت التسليم الفعلي، مدة التنفيذ، ولون **أحمر** إذا متأخرة.

## ٤. صفحة Team Members (للمدير وللأدمن)
- بطاقات الموظفين تظهر: الاسم + الوظيفة + شارة **Admin** إذا كان أدمن + الحالة + الأداء الفعلي.
- زر **Team** في صفحة المدير العام يفتح صفحة كاملة (مو مربع صغير) فيها بطاقات مدراء الأقسام.
- **Hover** على بطاقة مدير القسم → يظهر موظفين قسمه وأداءهم.

## ٥. نظام التقييم والأداء
- بعد تسليم الموظف للمهمة، **مدير القسم** يقيّمه من ٥ نجوم (جودة).
- بعد تسليم مدير القسم للمدير العام، **المدير العام** يقيّم مدير القسم من ٥ نجوم.
- الأداء = **٥٠٪ جودة (متوسط النجوم × ٢٠)** + **٥٠٪ التسليم بالوقت** (نسبة المهام المسلَّمة قبل الديدلاين).
- أداء القسم = متوسط أداء موظفيه.
- الرسم البياني للأداء يعكس هالحساب.

## ٦. View Project (للمدير العام)
- يفتح قائمة المشاريع، كل مشروع: عدد التاسكات + عدد أعضاء الفريق فيه.
- **Overdue tasks** = عدد التاسكات المتأخرة الفعلي.
- **Team members** = عدد الأقسام (مو الموظفين).

## ٧. نموذج إنشاء طلب تمويل
استبدال القوائم المنسدلة (Budget / Timeline / Stage / Type / Industry / Employees) بحقول **إدخال نصي حر**.

## ٨. مرفقات الموظفين
- إصلاح زر رفع الملف داخل المهمة (نفس مشكلة الـ bucket).
- الموظف يرفع → الطرف الثاني يقدر يحمّل (روابط تحميل تشتغل).

## ٩. التقويم / الديدلاين
- الشهر فوق التقويم يتغير ديناميكياً حسب الشهر المختار (مو ثابت "June").

## ١٠. الاجتماعات للأدمن
- إضافة خاصية **إنشاء اجتماعات** و**تقويم** للأدمن لكل قسم — نفس صلاحيات المدير العام بس مقصورة على قسمه.

## قاعدة البيانات (تعديلات مطلوبة)
- جدول `task_ratings` (تقييم النجوم).
- عمود `position` / `job_title` على `employees` (إذا ناقص) للوظيفة الظاهرة.
- bucket تخزين `task-files` + سياسات.
- تحديث enum الصلاحيات لإزالة `viewer`.

## ملاحظة مهمة
هالخطة كبيرة جداً وتحتاج عدة جولات (٤–٦ على الأقل). أقترح ننفذها بالترتيب التالي:

**الجولة الأولى (الأهم — إصلاح أعطال):**
1. إصلاح bucket رفع الملفات
2. إخفاء To Do/Done عند الأدمن
3. تفاصيل التاسك الكاملة للموظف
4. تقسيم تاسكات المدير العام لثلاث أعمدة

**الجولة الثانية:** التقييم بالنجوم + حساب الأداء + شارة Admin والوظيفة في البطاقات.

**الجولة الثالثة:** صفحة Team الكاملة + View Project + Overdue/Team count.

**الجولة الرابعة:** نموذج التمويل نصي + التقويم الديناميكي + اجتماعات الأدمن + تنظيف الصلاحيات.

أأكد البدء بالجولة الأولى؟ أو تبغى ترتيب مختلف؟
